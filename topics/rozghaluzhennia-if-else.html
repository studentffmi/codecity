Що має зрозуміти учень

  • Формулювати умову та визначати дві можливі дії.
  • Правильно записувати if і else з двокрапкою та відступом.
  • Перевіряти роботу програми для істинної й хибної умови.

Як пояснити тему

У житті ми постійно приймаємо рішення за умовою: якщо йде дощ — беремо парасолю, інакше виходимо без неї. Python робить те саме за допомогою розгалужень. Учень має зрозуміти не тільки синтаксис, а й те, як змінюється маршрут програми залежно від даних.

Перші завдання варто виконувати з двома граничними значеннями. Наприклад, якщо умова age >= 12, перевірити число 11 і число 12. Це допомагає побачити різницю між > та >= і звернути увагу на правильні відступи.

Приклад коду Python

Короткий навчальний приклад для розбору та обговорення на уроці:

age = int(input("Вік: "))
if age >= 12:
    print("Можна брати участь")
else:
    print("Спробуй наступного року")

Невелика практична задача

Зміни умову для перевірки мінімального зросту відвідувача атракціону та протестуй значення на межі допуску.
