Основа: наданий користувачем CODE_CITY_SITE_WAYFORPAY_READY(1).zip
Адреса GitHub Pages: https://studentffmi.github.io/codecity/

ВНЕСЕНО ЛИШЕ:
- SEO-метадані <head> у 5 існуючих HTML-сторінках (title, description, canonical, Open Graph, Twitter Card, robots).
- JSON-LD WebSite на головній сторінці.
- Нові технічні файли sitemap.xml та robots.txt.

НЕ ЗМІНЕНО:
- Жодного байта HTML після </head> у всіх п'яти сторінках.
- Увесь CSS і JavaScript, таймер, відео, кнопка WayForPay, фотографія, тексти та навігація.
- Усі файли у папці assets (побайтово).
- Жодної додаткової SEO-сторінки або розділу за темами.

ПУБЛІКАЦІЯ НА GITHUB:
Завантажити до кореня репозиторію codecity оновлені index.html, terms.html,
delivery.html, refund.html, contacts.html, sitemap.xml, robots.txt.
Вміст папки assets залишити без змін.

Далі: Search Console -> Sitemaps -> sitemap.xml; URL inspection головної сторінки.

ПОШУКОВІ ЗАПИТИ:
Погоджена семантика (48 загальних/тематичних формулювань + «Пайтон 7 клас»
та «Python 7 клас Ривкінд») залишається планом SEO, але метадані не можуть
забезпечити ранжування за кожною фразою без відповідного видимого вмісту.
Не використовували meta keywords: Google ігнорує цей тег.
